Geode Documentation

This is the official documentation for the Geode language.

Syntax

Syntax in Geode is similar to languages like C++ and C. Here is an example of a simple Geode program's syntax:


    str x = "countdown: ";
    print (x);
    int y = 10;
    bool b = false;
    while (y > 0) {
	    if (b) {
		    y = y + 1;
		    b = false;
	    } else {
		    y = y - 2;
		    b = true;
	    }
	    print (y);
    }
    print ("YAY");
