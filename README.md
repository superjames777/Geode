# Geode

Geode is a small, interpreted, and statically typed programming language built in C++. I made it for fun so don't expect to be blown away by it or anything.

## How to Run With Geode

To run a file with Geode, go to the [Github Releases](https://github.com/superjames777/Geode/releases) page and download the latest Geode release. Then you will want to add Geode to your system's PATH. Once you have added Geode to PATH, you can run a Geode file {example.geo} by running this in your OS' terminal:

```sh
geode example.geo
```
